# Voice-over & Captions

## Voice-over text

- Deliver the VO as numbered lines matching the storyboard scenes, with a duration per line.
- Arabic: write in the user's dialect with Arabic diacritics (تشكيل) ONLY on words a TTS engine is likely to misread. Most free Arabic TTS reads Egyptian dialect fine if spelled phonetically correct.
- Mark pauses with / (half second) and // (one second); most free TTS respects commas and periods, so also punctuate naturally.

## Generating the audio

Give exact steps for the chosen tool from free-tools.md, e.g. for WevoLabs: open site, paste one scene's line, pick an Egyptian Arabic voice, download MP3, repeat per scene. One file per scene makes CapCut timing much easier than one long file.

## Captions

- Short-form videos get watched muted: captions are mandatory, not optional.
- Wording: 3-5 words per caption line, matching the VO, not the full sentence.
- Placement: lower third but above the TikTok UI (roughly the bottom 15% is covered by buttons on phones); center-bottom, large, bold, with a dark outline or background chip.
- One accent color for the keyword of each caption; the rest white.
- In CapCut: Text -> Auto captions (supports Arabic) then fix mistakes by hand, or add manual text layers timed to each scene.
- Emphasis timing: the keyword should appear exactly when it is spoken.
