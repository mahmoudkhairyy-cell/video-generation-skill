# Assembly (CapCut, phone)

The user-facing recipe. Keep it to short numbered steps in the user's language; never more than ~7 steps.

## Route A (HTML motion reel)

1. Open the artifact fullscreen in the browser first (tap the artifact, then open it in the browser, or download the file and open it). Rotate to portrait, scroll to hide the URL bar / use "Add to Home Screen" for a clean full-screen.
2. Turn on Do Not Disturb. Start the built-in screen recorder, then press play / reload the page. Let it play to the end card, stop recording.
3. Trim the recording's start/end in the gallery so it begins on the first frame.
4. Make the voice-over: paste the VO lines into the free TTS site (see free-tools.md), download the mp3 — or record your own voice in CapCut.
5. CapCut → New project → import the trimmed recording → Audio → add the VO mp3 → drag to align each line with its scene; use Speed or Split on the video if a scene runs short/long.
6. Captions are already inside the reel, so skip auto-captions. Optional: Audio → Music, low volume (~-20dB under the VO).
7. Export 1080p. Delete CapCut's auto-added outro clip before exporting to avoid the watermark.

## Route B (AI footage)

Same, except step 1–3 become: generate each scene's clip in the free generator (one prompt per scene, vertical 9:16), download the mp4s, import them in scene order in CapCut. Then VO, captions, music, export as above.

## Common fixes

- Reel longer than VO → increase scene durations in the HTML timing array (one edit) and re-record, or stretch scenes in CapCut.
- VO longer than reel → speed the VO to 1.05–1.1x in CapCut, or shorten pauses.
- Recording shows the browser UI → crop in CapCut (9:16 canvas) or re-record full-screen.
