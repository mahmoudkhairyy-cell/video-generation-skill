# Scene prompts for AI generators (Route B only)

Use only when the user wants realistic/generated footage instead of the flat motion style.

## Prompt formula

`[shot type] + [subject] + [action] + [setting] + [lighting/mood] + [style] + vertical 9:16`

Write prompts in English (generators understand it best), keep each under ~60 words, one clear action per clip, consistent subject description across scenes (repeat the same descriptors verbatim so the character/product looks the same in every clip).

Example: "Medium shot, young Egyptian man in a white shirt, talking excitedly to camera, bright Cairo apartment, warm morning light, realistic style, vertical 9:16"

## Rules

- 3–8 seconds per generated clip; one action per clip.
- Set vertical/portrait/9:16 in the tool before generating.
- Negative prompt when supported: "text, watermark, logo, distorted hands, extra fingers, blurry".
- Never put Arabic words inside the generated footage (renders garbled) — Arabic text goes on top in CapCut.
- Image→video when a consistent character matters: generate one still first, then animate it.
