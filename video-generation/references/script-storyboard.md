# Script and storyboard

## Script

- Hook first: the first line must create curiosity or promise the result in under 2 seconds ("الفيديو ده اتعمل من سطر واحد", "من غير برامج ولا فلوس").
- 6–10 short lines total, 30–60 seconds when spoken. One idea per line. Punchy, spoken language (default Egyptian-friendly Arabic unless the user asks otherwise).
- Structure: hook → what it is → how (numbered steps or scenes) → proof/result → CTA line.
- Write the CTA exactly as the user wants it (e.g. "اللينك في البايو"). No unverifiable claims, no earnings promises.
- Number the lines. Next to each line, note the approximate spoken seconds (1s per 2–2.5 Arabic words).

## Storyboard / scene plan

For each scene output: scene number, duration (s), the on-screen headline text (short — the headline is NOT the whole VO line, it is the punch of it), the visual elements (flat shapes, mockups, icons — nothing filmed), and the motion (slide, pop, highlight swipe, waveform).

Rules:
- One scene per 1–2 script lines. 6–10 scenes.
- Palette per VIDEO, not per scene: one background + one ink + one accent. Change the palette between different videos so they never look identical. A single dark "contrast scene" in the middle is allowed.
- Typography does the heavy lifting: huge bold Arabic headline + number chip + small Latin sub-label (STEP 0X / 06 style).
- Keep 2–4 elements per scene. Empty space is part of the style.
