# Free tools (verified categories — confirm limits on the day, they change)

Everything must work from Egypt, on a phone browser, without a credit card.

## Screen recording (Route A render) — built in, free

- iPhone: Control Center → Screen Recording (enable in Settings → Control Center). No time limit.
- Android: Quick Settings → Screen recorder (Samsung/Xiaomi/native Android 11+ all have it).
- Tip for the user: full-screen the browser (hide the URL bar by scrolling/landscape-then-portrait or "Add to Home Screen" then open), silence notifications first.

## Arabic TTS (voice-over mp3) — free, no card

- WevoLabs TTS (wevo.ai / wevolabs): free Arabic voices, no login, MP3 download.
- SpeechGen (speechgen.io): free quota, Arabic (Egypt) voices, MP3.
- Microsoft Edge "Read aloud" on desktop or edge-tts: free natural Arabic voices (Hamed/Salma) — only if the user happens to be on a PC; not the default path.
- Fallback: user records their own voice in CapCut (Audio → Record). Often the most natural result.
- Pick ONE site in the instructions, not a list — the user is on a phone.

## Assembly — CapCut app (free)

- Import screen recording + VO mp3 → align → auto-captions (Arabic) → optional music → export 1080p.
- CapCut is free from Egyptian app stores; watermark can be removed by deleting the outro clip.

## Route B: AI video/image generators (only for realistic footage requests)

Daily free credits, usable from Egypt, phone browser OK. Limits change; the user may need to try the next one if a quota is out:
- Kling AI (klingai.com) — daily free credits, text/image→video.
- Hailuo / MiniMax (hailuoai.video) — daily free credits.
- PixVerse, Vidu — similar free daily credits.
- Dreamina (dreamina.capcut.com) — free daily credits, image and video.
- Still images: Bing Image Creator (free with Microsoft account), Ideogram (free daily), Pollinations (keyless, free).
Warn honestly: queues can be long, watermarks vary, and Arabic text inside generated images is unreliable — keep Arabic text as CapCut overlays, never inside generated footage.

## What NOT to recommend

- Paid plans, "free trials" needing a card, VPN workarounds, or desktop-only software. If a tool starts requiring payment, swap it for another from this list.
